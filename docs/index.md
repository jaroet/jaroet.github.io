# JaRoet

A creative contraction of my name that I use as my developername on Github. 

At the end of december 22025 I started working on a new PKM tool. I started in a new job recently at a big company and the use of the laptop is very restricted. Unable to install anything except what is explicitely allowed. 

Coming from Obsidian / Logseq / Tangent Notes in different combinations I lost easy access to almost 3000 notes. The markdown files where still there but not accessable using the nice features the mentioned tools delivered. 

I started on http://aistudio.google.com and quickly had a proof-of-concept. I kept working on it about a month, trying stuff and learning how to use the AI and how to switch to Gemini chat in Visual Studio Code. I then decided to start over, for a bit at least. That resulted in [PKM Outliner](pkmoutliner/index.md).
