# JaRoet

A contraction of my first names and part of my lastname that I use as my developername on Github.  

I started this page when I was working on an alternative PKM solution. Coming from **Obsidian** / **Logseq** / **Tangent Notes** in different combinations I lost easy access to almost 3000 notes when I started working for a company the restricts installation of unauthorized software (first time in 30 years). 
The markdown files are still there but not accessable using the nice features the mentioned tools delivered. And managing 3000+ files using a simple text-editor and the file manager was sub-optimal.  

So I started on http://aistudio.google.com and quickly had a proof-of-concept. I kept working on it about a month, trying stuff and learning how to use the AI and how to switch to Gemini chat in Visual Studio Code. 

The tools name is JaRoet's pkm-outliner and its concept is loosely based on tools like TheBrain, Obsidian, Logseq, Tangent Notes and many others. Without the restrictions I ran into on my work I would probably be using and one of those tools now. Most likely TheBrain now it is free for desktop use. 

After the initial version I then decided to start over. For a bit at least. That resulted in [PKM Outliner](pkmoutliner/index.md). 

## personal story
I am no developer. At work I handle data in different forms and roles. From data engineer to BI specialist and it is something I do like very much. But programming software always interested me but I found it very seldom being worth the effort. Tools and language are extremely difficult to become good in. Every start is simple but before you can really make something usefull it takes up a load of time. For me the use of AI made that less of an issue for me as I do not need to now how I can program but I only need to know what I want. 

I also do not need fancy features in my PKM tool or AI on my data. I do not need a task manager but only a place I can store my knowledge, link to it in different ways, have it discoverable and for me alone, nobody else. So I do not need online sync for example. I find it far more easier to use Dynalist, Checkvist or even Google Keep to make notes when I am on the go and sync them manually to my central vault when I have the time.
